# REST service for WCM v2

This section discusses how to use the Web Content Manager (WCM) REST version 2 APIs. 

-   **[Getting started with the REST service for WCM v2](wcm_rest_v2_starting.md)**   
You can use WCM REST V2 APIs to manage Web Content. The REST service for WCM provides authoring access to content items and elements.
