# What's new in CF239

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF239 on supported platforms:

- Add custom attributes using Helm
- Append entries to WebEngine `.properties` files using Helm values
- Helm values updates
- Import personalization rules programmatically
- IQ - Configuring cross-session memory
- IQ - HTTPS support for the MCP Server
- Nested LDAP groups
- OpenLiberty, JRE, and UBI versions
- Practitioner Studio Dashboard - New widgets
- Search V2 - Search Admin UI
- User Session Reporting Tool - New `-assumeClientIP` flag

## Add custom attributes using Helm

You can now configure custom attributes for users and groups in HCL DX Compose by using the Helm `configOverrideFiles` parameter instead of manually updating the `server.xml` file. This capability extends the default schema to store organization-specific data for `PersonAccount` and `Group` entities across Kubernetes deployments. For more information, refer to [Adding custom attributes in DX Compose](../deploy_dx/manage/working_with_compose/cfg_parameters/adding_custom_attributes.md).

## Append entries to WebEngine `.properties` files using Helm values

You can now append raw lines to WebEngine properties files by using the `configuration.webEngine.propertiesFilesAdditions` Helm value. Use this capability when you need to add entries that must remain raw lines instead of key-value properties, such as `MemberFixerModule.properties` mappings. For more information, refer to [Appending entries to WebEngine `.properties` files using Helm values](../deploy_dx/manage/cfg_webengine/update_properties_additions_with_helm.md).

## Helm values updates

Helm value properties in HCL DX Compose that were added, removed, or changed for this release are documented in [DX Compose Helm values updates](dx_helm_values_updates.md#cf239).

## Import personalization rules programmatically

You can now import personalization rules exported from an HCL DX Core or HCL DX Compose environment directly into a target workspace by sending an HTTP POST request to the `pznpublish/pznpublishtarget` endpoint. For more information, refer to [Importing personalization rules programmatically](../deploy_dx/manage/cfg_webengine/pzn_import.md).

## IQ - Configuring cross-session memory

You can now enable the optional cross-session memory feature in IQ. This feature allows IQ to store and reference context from past conversations. To enable cross-session memory, set `RAG_ENABLED` to `true` in your `custom-iq-values.yaml` file and upgrade the Helm release. For more information, refer to [Configuring cross-session memory](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/iq/installation/enable-rag/){target="_blank"}.

## IQ - HTTPS support for the MCP Server

IQ now supports HTTPS to secure connections between the MCP server and the IQ Integrator. HTTPS is disabled by default. For configuration instructions, refer to [Enabling HTTPS for the MCP Server](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/iq/installation/configuring-mcp/#enabling-https-for-the-mcp-server){target="_blank"}.

## Nested LDAP groups

The Users and Groups UI now displays child groups within nested LDAP groups. You can navigate through the group hierarchy to view direct members and identify which child group each user belongs to. Configure nested LDAP groups by setting the `recursiveSearch` attribute of the `ldapRegistry` element to `false` (default) in your `server.xml` file, or omitting it. Setting this attribute to `true` flattens nested groups into a single list in the UI and hides child-group relationships.

!!!note
    By default, DX Compose now resolves all parent groups that a user belongs to during login for authentication and access control without requiring recursive search.

For configuration details and guidance, refer to [Configuring nested LDAP groups](../deploy_dx/manage/working_with_compose/cfg_parameters/manage_users_groups_liberty.md#configuring-nested-ldap-groups) and [Configuring LDAP](../deploy_dx/manage/cfg_webengine/configuration_changes_using_overrides.md#configuring-ldap).

## Practitioner Studio Dashboard - New widgets

The Practitioner Studio Dashboard now includes two widgets to help you monitor content schedules and search indexing:

- **Calendar**: Displays a monthly or weekly grid and daily agenda of content based on publish and expiry dates.
- **Search Crawlers**: Displays the status of Search V2 crawlers.

For more information, refer to [Calendar](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/practitioner_studio/dashboard/#calendar){target="_blank"} and [Search Crawlers](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/practitioner_studio/dashboard/#search-crawlers){target="_blank"}.

## Search V2 - Search Admin UI

The Search Admin UI provides a centralized interface for managing Search V2 components. Administrators can configure content sources, crawlers, common field mappings, and native language support (NLS) translations from a single dashboard. You can access the UI either as a standalone application or directly within Practitioner Studio. For more information, refer to [Search Admin UI](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/search_v2_admin_ui/){target="_blank"}.

## User Session Reporting Tool - New `-assumeClientIP` flag

The User Session Reporting Tool now includes an optional `-assumeClientIP` command-line flag. This flag is designed for deployments utilizing complex proxy chaining, such as Akamai combined with IBM HTTP Server (IHS). When enabled, it instructs the tool to extract only the first IP address from the `X-Forwarded-For` header to use as the stable client IP, preventing session fragmentation. For more information, refer to [Handling the routing setup](https://help.hcl-software.com/digital-experience/9.5/latest/get_started/download/software_licensing_portal/configure_entitlement_checks/user_session_reporting_tool/#handling-the-routing-setup) and [Generating user session data usage in MHS metrics format](https://help.hcl-software.com/digital-experience/9.5/latest/get_started/download/software_licensing_portal/configure_entitlement_checks/configuring_mhs_file_base_session_reporting/#generating-user-session-data-usage-in-mhs-metrics-format-traditional-deployment).
