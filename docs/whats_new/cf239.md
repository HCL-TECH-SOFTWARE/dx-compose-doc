# What's new in CF239

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF239 on supported platforms:

- Add custom attributes using Helm
- Helm values updates
- OpenLiberty, JRE, and UBI versions

## Add custom attributes using Helm
You can now configure custom attributes for users and groups by using Helm instead of manually updating `server.xml`. For more information, refer to [Adding custom attributes in DX Compose](../deploy_dx/manage/working_with_compose/cfg_parameters/adding_custom_attributes.md).

## Helm values updates

Helm value properties in HCL DX Compose that were added, removed, or changed for this release are documented in [DX Compose Helm values updates](dx_helm_values_updates.md#cf239).

## OpenLiberty, JRE, and UBI versions <!--update links-->

HCL DX Compose 9.5 CF239 contains the following:

- [OpenLiberty 26.0.0.8](../getting_started/system_requirements.md#openliberty)
- [Java Runtime Environment (JRE) IBM Semeru Runtime Open Edition 21.0.12.0 (build 21.0.12+x-LTS)](../getting_started/system_requirements.md#java-runtime-environment)
- [Red Hat Universal Base Image (UBI): 9.8-1786380870](../deploy_dx/install/kubernetes_deployment/image_list.md#hcl-dx-compose-ubi-levels)

For more information, refer to [OpenLiberty, JRE, and UBI versions](../deploy_dx/install/kubernetes_deployment/kubernetes_runtime.md#openliberty-jre-and-ubi-versions).
