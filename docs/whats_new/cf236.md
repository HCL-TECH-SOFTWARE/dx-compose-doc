# What's new in CF236

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF236 on supported platforms:

- Configuring `recursiveSearch` in `values.yaml`
- DX Compose IQ assistant now available
- Helm values updates
- OpenLiberty and JRE versions
- OpenTelemetry Integration Guide

## Configuring `recursiveSearch` in `values.yaml`

You can now configure the `recursiveSearch` parameter directly in your `values.yaml` file. This parameter allows DX Compose to resolve inherited user memberships by searching through nested LDAP sub-groups. By default, the parameter is set to `false`. If users in nested groups are missing permissions, you can toggle it to `true` directly within your Helm deployment configuration instead of applying manual overrides.

Nested group membership is supported when your LDAP server provides recursive server-side group search, or when the `recursiveSearch` option is enabled in DX Compose. This ensures users in nested groups are correctly resolved for authentication and authorization. For more information, refer to [Configuring LDAP](../deploy_dx/manage/cfg_webengine/configuration_changes_using_overrides.md#configuring-ldap).

## DX Compose IQ assistant now available <!--UPDATE LINK-->

IQ is an AI-powered assistant integrated into HCL Digital Experience (DX) Compose that provides real-time, context-aware assistance to help you accomplish tasks more efficiently. Built on the Model Context Protocol (MCP), IQ offers a conversational interface directly within the DX Compose environment, enabling you to interact with AI capabilities seamlessly while managing content and sites.

You can interact with the assistant in two ways:

- **In the DX Compose toolbar:** Select the **Open IQ chat** sparkle button in the top toolbar on standard DX pages to open the panel view sidebar.
- **In Site Templates pages:** Select the **Open IQ chat** floating sparkle button to open the compact view chat window.

To enable IQ, go to [Enabling and disabling IQ](../deploy_dx/manage/cfg_dx_compose/enable_iq.md). For more information on the assistant, refer to [IQ](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/build_sites/iq/){target="_blank"}.
