# What's new in CF236 

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF236 and the HCL Java Transition Module for DX Compose CF236 on supported platforms:

- Configuring `recursiveSearch` in `values.yaml`
- Exporting and importing a web content library copy now available
- Helm values updates
- IQ assistant now available
- Java Transition Module for DX Compose - Support for additional custom Java extension types
- OIDC authentication filter update for Site Builder
- OpenLiberty, JRE, and UBI versions
- OpenTelemetry Integration now available
- Presentation Designer - DAM integration and feature updates

## Configuring `recursiveSearch` in `values.yaml`

You can now configure the `recursiveSearch` parameter directly in your `values.yaml` file. This parameter allows DX Compose to resolve inherited user memberships by searching through nested LDAP sub-groups. By default, the parameter is set to `false`. If users in nested groups are missing permissions, you can toggle it to `true` directly within your Helm deployment configuration instead of applying manual overrides.

Nested group membership is supported when your LDAP server provides recursive server-side group search, or when the `recursiveSearch` option is enabled in DX Compose. This ensures users in nested groups are correctly resolved for authentication and authorization. For more information, refer to [Configuring LDAP](../deploy_dx/manage/cfg_webengine/configuration_changes_using_overrides.md#configuring-ldap).

## Exporting and importing a web content library copy now available

You can now export and import web content library copies in HCL DX Compose. Export a web content library to disk by creating a copy of the library. Then, import the copy into the same server multiple times. Each import creates a new library without affecting existing copies. This approach provides a quick way to create fully populated libraries that you can adapt for other purposes. For more information, refer to [Exporting and importing a web content library copy](../deploy_dx/manage/cfg_webengine/wcmlibrary_exportcopy.md).

## IQ assistant now available

IQ is an AI-powered assistant integrated into HCL DX Compose that provides real-time, context-aware assistance to help you accomplish tasks more efficiently. Built on the Model Context Protocol (MCP), IQ offers a conversational interface directly within the DX Compose environment, enabling you to interact with AI capabilities seamlessly while managing content and sites.

You can interact with the assistant in two ways:

- **In the DX Compose toolbar:** Select the **Open IQ chat** sparkle button in the top toolbar on standard DX pages to open the panel view sidebar.
- **In Site Templates pages:** Select the **Open IQ chat** floating sparkle button to open the compact view chat window.

To enable IQ, go to [Enabling and disabling IQ](../deploy_dx/manage/cfg_dx_compose/enable_iq.md). For more information on the assistant, refer to [IQ](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/iq/){target="_blank"}.

## OIDC authentication filter update for Site Builder

A new configuration option is available to resolve site creation failures in environments using OpenID Connect (OIDC). You can now add the `excludeSiteBuilderResource` exclusion pattern to the OIDC authentication filter (`authFilter`).

This parameter prevents OIDC from intercepting internal server-to-server calls initiated by the Site Builder background task. Excluding these programmatic calls ensures that site creation completes successfully instead of failing due to a lack of browser context during identity provider redirects. For more information, refer to [Enabling OIDC authentication in DX Compose](../deploy_dx/manage/cfg_webengine/configure_compose_to_use_oidc.md#enabling-oidc-authentication-in-dx-compose).

## Presentation Designer - DAM integration and feature updates

You can now insert Digital Asset Management (DAM) assets directly into your Presentation Designer canvas. The **Image configuration** panel now includes a native DX picker dialog to choose and apply DAM assets directly to the canvas, eliminating manual URL copying and ensuring automatic metadata cleanup when switching asset sources. For more information, refer to [Static elements - Images](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/presentation_designer/usage/user_elements/#static-elements){target="_blank"}.

Additional updates include the following enhancements:

- Multiple workspace notifications now queue vertically in the bottom-left corner instead of overwriting active messages, allowing you to track rapid operations sequentially. For more information, refer to [Accessing Presentation Designer - Notifications](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/presentation_designer/access/#notifications){target="_blank"}.
- **Grid** elements now include **Auto-flow** and **Area layout** configurations to support independent layout behavior across **Desktop**, **Tablet**, and **Mobile** viewports. **Tablet** and **Mobile** layouts allow count-based overrides that automatically recalculate row or column tracks without modifying the baseline **Desktop** layout. For more information, refer to [Static elements - Grid](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/presentation_designer/usage/user_elements/#static-elements){target="_blank"}.
- The **Back** button now synchronizes the return URL during initialization, ensuring you return to your previous workspace view with your context intact, even if the user interface language changes mid-session. For more information, refer to [Accessing Presentation Designer - Toolbar](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/presentation_designer/access/#toolbar){target="_blank"}.
