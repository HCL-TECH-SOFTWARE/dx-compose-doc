# What's new in CF238

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF238 on supported platforms:

- Core Editor - New rich text editor option
- DAM - Enhanced staging to handle secret rotation
- DAM - New parameters for setting the initial collections view
- Helm values updates
- LDAP virtual portal realm support now available
- New parameters for configuring secrets
- OpenLiberty, JRE, and UBI versions
- Practitioner Studio Dashboard - New widgets
- Presentation Designer - Feature updates
- WCM REST API v3 now available

## Core Editor - New rich text editor option <!--update link-->

Core Editor is now available as an optional rich text editor for HCL Web Content Manager. You can use this editor as an alternative to the Enhanced (TinyMCE) and Advanced (CKEditor) rich tech editors in both the WCM Authoring Portlet and Site Manager in-place editing. For more information about the Core Editor, including a list of features supported and limitations, refer to [Configuring Core Editor](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/wcm_configuration/cfg_webcontent_auth_env/wcm_config_core_editor/){target="_blank"}.

## DAM - Enhanced staging to handle secret rotation <!--update link-->

DAM staging in HCL DX now supports periodic heartbeat verification to manage subscriber connections during secret rotation. The system uses the [SubscriberInterfaceController](https://opensource.hcltechsw.com/experience-api-documentation/dam-api/#tag/SubscriberInterfaceController){target="_blank"} API endpoint to detect connectivity issues and automatically disable or re-enable subscribers when authentication credentials change.

Configure the verification frequency by using the `verifySubscribersIntervalInMinutes` Helm parameter in `values.yaml`. For more information, refer to [Verifying subscriber connectivity during secret rotation](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/configuration/staging_dam/dam_subscription_staging/#verifying-subscriber-connectivity-during-secret-rotation){target="_blank"}.

## DAM - New parameters for setting the initial collections view <!--update link-->

You can now configure the initial view for Digital Asset Management (DAM) collections using the configuration.digitalAssetManagement.defaultView Helm value. Supported values are grid and list. For more information, refer to Step 3 of [Browsing and searching for media assets in a collection](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/usage/managing_dam/manage_collections/#browsing-and-searching-for-media-assets-in-a-collection){target="_blank"}.

## Helm values updates

Helm value properties in HCL DX Compose that were added, removed, or changed for this release are documented in [DX Compose Helm values updates](dx_helm_values_updates.md#cf238).

## LDAP virtual portal realm support now available

You can now configure DX Compose to support multiple OpenLDAP servers with dedicated realms. These realms restrict user access and initial administration groups per virtual portal. You can also combine multiple realms under a parent realm by using the `federatedRealms` extension. For more information, refer to [Configuring LDAP settings for virtual portal realm support](../deploy_dx/manage/cfg_webengine/configuration_changes_using_overrides.md#configuring-ldap-settings-for-virtual-portal-realm-support).

## New parameters for configuring secrets

Two new parameters are now available to control how custom secrets are applied to pods. Use `environmentVariable` and `file` in your `values.yaml` file to configure environment variable injection and file mounting independently. For more information, refer to [Configuring file mounting and environment variables](../deploy_dx/manage/working_with_compose/custom_secrets.md#configuring-file-mounting-and-environment-variables).

## Practitioner Studio Dashboard - New widgets <!--update links-->

The Practitioner Studio Dashboard introduces two new widgets to streamline site navigation and content management:

- **My Sites**: Displays your managed sites as visual cards with thumbnails, status indicators, and direct access links.
- **Recently Modified Pages**: Displays an expandable tree structure and search tool to quickly locate and open recent modified pages.

For more information, refer to [My Sites](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/build_sites/practitioner_studio/dashboard#my-sites){target="_blank"} and [Recently Modified Pages](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/build_sites/practitioner_studio/dashboard#recently-modified-pages){target="_blank"}.

## Presentation Designer - Feature updates <!--update links-->

The following features are now available in Presentation Designer:

- You can use the **Custom HTML** static element to embed raw HTML markup directly into a presentation template using a resizable, syntax-highlighted code editor. The element renders inside a shadow DOM host so custom `<style>` rules do not leak into the document layout. Scripts and event handlers are also disabled during authoring but run normally in saved output. For more information, refer to [Custom HTML](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/wcm_authoring/presentation_designer/usage/user_elements/static_elements/#custom-html){target="_blank"}.
- You can resize the **Container** and **Grid** static elements directly on the canvas by dragging the handles (top, right, bottom, or left) that appear around its edges. This provides a more interactive alternative to resizing these elements from the **Style items** panel. For more information, refer to [Static elements](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/wcm_authoring/presentation_designer/usage/user_elements/static_elements/){target="_blank"}.
- You can use the **Save as draft** option to save your presentation template as a **Draft override stylesheet**. This stylesheet saves your in-progress style edits into a separate file, ensuring that the CSS of the live or published presentation template is not accidentally overwritten or partially broken while you are actively staging layout or style changes. For more information, refer to [Saving a presentation template as a draft](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/wcm_authoring/presentation_designer/usage/edit_presentation_template#saving-a-presentation-template-as-a-draft){target="_blank"} and [Draft override stylesheet](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/wcm_authoring/presentation_designer/usage/default_and_override_stylesheet#draft-override-stylesheet){target="_blank"}.

## WCM REST API v3 now available

A modern REST API for Web Content Manager (WCM) is now available. WCM REST API v3 provides streamlined access to WCM content, libraries, site areas, categories, taxonomies, and presentation templates with simplified JSON payloads, OpenAPI 3.0 integration, and a built-in API Explorer. For more information, refer to [REST service for Web Content Manager v3](../deploy_dx/manage/working_with_compose/wcm_rest_v3/index.md) and [Enabling and disabling the Web Content Manager REST API v3 service](../deploy_dx/manage/cfg_dx_compose/enable_wcm_api_v3.md).
