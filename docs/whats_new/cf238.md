# What's new in CF238

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF238 on supported platforms:

- Helm values updates
- OpenLiberty and JRE versions

## Helm values updates <!--update values-->

Helm value properties in HCL DX Compose that were added, removed, or changed for this release are documented in [DX Compose Helm values updates](dx_helm_values_updates.md#cf238).

## OpenLiberty and JRE versions <!--update values-->

HCL DX Compose 9.5 CF238 contains the following:

- [OpenLiberty 26.0.0.3](../getting_started/system_requirements.md#openliberty)
- [Java Runtime Environment (JRE) IBM Semeru Runtime Open Edition 21.0.9.0 (build 21.0.9+10-LTS)](../getting_started/system_requirements.md#java-runtime-environment)

For more information, refer to [OpenLiberty, JRE, and UBI versions](../deploy_dx/install/kubernetes_deployment/kubernetes_runtime.md#openliberty-jre-and-ubi-versions).
