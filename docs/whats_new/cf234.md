# What's new in CF234

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF234 on supported platforms:

- Basic registry configuration is now managed using Helm
- DAM - New actions available in Database Analysis
- SpellCheck service now supported

## Basic registry configuration is now managed using Helm

You can now configure the default basic registry using Helm instead of the hardcoded Liberty server configuration. This change provides greater flexibility in managing authentication sources and enables production deployments to rely exclusively on external LDAP directories without maintaining file-based credentials.

For detailed information on configuring the default basic registry, refer to [Configuring the default basic registry](../deploy_dx/manage/cfg_webengine/default_basic_registry_configuration.md).

## DAM - New actions available in Database Analysis <!--Update URLs-->

New actions are now available in the Database Analysis feature of HCL Digital Asset Management (DAM). You can now retrigger failed operations, generate access references, and move orphaned media items into your desired collections. For more information on these new actions, refer to [Operations Metrics](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/usage/managing_dam/database_analysis/#operations-metrics){target="_blank"}, [Collections Missing Access Reference ID](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/usage/managing_dam/database_analysis/#collections-missing-access-reference-id){target="_blank"}, and [Media Items not in Collection](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/usage/managing_dam/database_analysis/#media-items-not-in-collection){target="_blank"}.

## SpellCheck service now supported

The SpellCheck service for the TinyMCE Rich text editor is now supported in DX Compose. For more information on this feature, refer to [Setting up a remote spell checker](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/deployment/manage/remote_spell_checker/){target="_blank"}.
