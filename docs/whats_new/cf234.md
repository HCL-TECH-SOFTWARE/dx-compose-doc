# What's new in CF234 

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF234 on supported platforms:

- Basic registry configuration is now managed using Helm
- DAM - New actions available in Database Analysis
- Deploying custom portlets using the Java Transition Module
- OpenLiberty and JRE versions
- Presentation Designer - Canvas Context Preview
- Search V2 - Expanded support for Certificate DNs
- SpellCheck service now supported
- WCM AI Sentiment Analysis now supported
- WCM AI Analysis - New configuration options for custom AI providers
- Woodburn Studio demo site installation removed

## Basic registry configuration is now managed using Helm

You can now configure the default basic registry using Helm instead of the hardcoded OpenLiberty server configuration. This change provides greater flexibility in managing authentication sources and enables production deployments to rely exclusively on external LDAP directories without maintaining file-based credentials.

For detailed information on configuring the default basic registry, refer to [Configuring the default basic registry](../deploy_dx/manage/cfg_webengine/default_basic_registry_configuration.md).

## DAM - New actions available in Database Analysis

New actions are now available in the Database Analysis feature of HCL Digital Asset Management (DAM). You can now retrigger failed operations, generate access references, and move orphaned media items into your desired collections. For more information on these new actions, refer to [Operations Metrics](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/digital_assets/usage/managing_dam/database_analysis/#operations-metrics){target="_blank"}, [Collections Missing Access Reference ID](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/digital_assets/usage/managing_dam/database_analysis/#collections-missing-access-reference-id){target="_blank"}, and [Media Items not in Collection](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/digital_assets/usage/managing_dam/database_analysis/#media-items-not-in-collection){target="_blank"}.

## Deploying custom portlets using the Java Transition Module

You can now deploy custom portlets if you have purchased the HCL Java Transition Module for DX Compose. This module provides services and extensions to install Java-based workloads on the DX Compose platform, allowing you to transition key Java workloads deployed to HCL DX solutions on the IBM WebSphere Application base to operate on the DX Compose platform.

If you are entitled to the HCL Java Transition Module for DX Compose, you can find the installation documentation in your [My HCLSoftware (MHS)](https://support.hcl-software.com/csm?id=kb_article&sysparm_article=KB0109011){target="_blank"} portal entitlement downloads.

## OpenLiberty and JRE versions

HCL DX Compose 9.5 CF234 contains the following:

- OpenLiberty 25.0.0.12
- Java Runtime Environment IBM Semeru Runtime Open Edition 21.0.9.0 (build 21.0.9+10-LTS)

## Presentation Designer - Canvas Context Preview

The Canvas Context Preview feature in Presentation Designer lets you preview how presentation templates render with Web Content Manager (WCM) content items. Visualizing templates with real data helps you verify layouts and data mapping across different device views before publishing. For more information on this feature, refer to [Canvas Context Preview in Presentation Designer](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/presentation_designer/usage/context_preview/){target="_blank"}.

## Search V2 - Expanded support for Certificate DNs

The Search V2 backend now supports comprehensive Distinguished Name (DN) validation and role mapping for administrative certificates. This update ensures compatibility with complex organizational security standards by supporting seven core attribute types: `CN`, `OU`, `O`, `L`, `ST`, `C`, and `DC`.

The OpenSearch entrypoint script now automatically parses the Common Name (CN) from your `adminDN` and maps it to the `all_access` administrative role in the security configuration. For more information refer to [Installing the Search V2 backend](https://help.hcl-software.com/digital-experience/9.5/latest/deployment/install/container/helm_deployment/preparation/optional_tasks/optional_install_new_search/){target="_blank"}.

## SpellCheck service now supported

The SpellCheck service for the Enhanced Rich Text Editor (TinyMCE) is now supported in DX Compose. SpellCheck is enabled by default and requires no additional configuration.

## WCM AI Sentiment Analysis now supported

The Web Content Manager (WCM) AI Sentiment Analysis feature in the WCM Authoring user interface (UI) is now supported for the TinyMCE Rich text editor and CKEditor in DX Compose. For more information on this feature, refer to [WCM Content AI Analysis](https://help.hcl-software.com/digital-experience/9.5/latest/get_started/plan_deployment/traditional_deployment/wcm_env/wcm_ai_analysis/){target="_blank"}.

## WCM AI Analysis - New configuration options for custom AI providers

You can set custom configurations to connect the default AI provider to alternative, OpenAI-compatible services using the following parameters:

- `OPENAI_MODEL`
- `OPENAI_MAX_TOKENS`
- `OPENAI_TEMPERATURE`
- `OPENAI_HOST`
- `OPENAI_SCHEME`

For more information on these configuration options, refer to [OPEN_AI provider configuration](../deploy_dx/manage/cfg_dx_compose/enable_content_ai.md#open_ai-provider-configuration).

## Woodburn Studio demo site installation removed

The Woodburn Studio demo site in HCL DX was deprecated on August 5, 2025, and will reach End of Support (EOS) on August 4, 2026. Starting from CF234, Woodburn Studio is no longer installed out-of-the-box for DX Compose offerings. For more information, see [Deprecated features](https://help.hcl-software.com/digital-experience/9.5/latest/whatsnew/deprecated_features/#recently-deprecated-features){target="_blank"}.
