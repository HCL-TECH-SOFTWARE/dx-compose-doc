# What's new in CF235

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF235 on supported platforms:

- Basic registry and administrator identity are now fully configurable
- DAM - Soft Delete
- OpenLiberty and JRE versions
- Practitioner Dashboard
- Presentation Designer - New entry points from Authoring portlet
- Search V2 - Using in-house CA or PKI for certificates

## Basic registry and administrator identity are now fully configurable

The basic registry and administrator identity configuration are now fully configurable in DX Compose. This update enables the following capabilities:

- **Disable the basic registry** for LDAP-only deployments by setting `basicRegistry.enabled` to `false`.
- **Customize the realm name** by setting `basicRegistry.realm` to a custom value.
- **Change the administrator username** from `wpsadmin` to a custom value by using `webEngineUser` or `customWebEngineSecret`. When you use LDAP, the administrator user does not need to exist in the basic registry and can be an LDAP user.
- **Change the administrator group** from `wpsadmins` to a custom value by using `webEngineAdminGroup`. When you use LDAP, you can specify an LDAP group DN instead of a basic registry group.

For more information, see [Configuring the default basic registry](../deploy_dx/manage/cfg_webengine/default_basic_registry_configuration.md) and [Configuring the administrator user and group](../deploy_dx/manage/cfg_webengine/configure_default_admin_user.md).

## DAM - Soft Delete <!--UPDATE URL-->

The Soft Delete feature provides a safety net for accidental deletions of assets and collections in Digital Asset Management (DAM). Instead of permanently removing items immediately, a soft delete moves them to a **Trash** state where they are hidden from normal views but remain in the database for a configurable period. Items in the Trash can be restored or permanently deleted by authorized users. For more information, refer to [DAM Soft Delete](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/configuration/dam_soft_delete/){target="_blank"}.

## Practitioner Dashboard <!--UPDATE URL-->

The Practitioner Dashboard is a modern, React-based dashboard with widgets, quick links, and an info hub to help you manage content, track status, and personalize user experiences more efficiently. For more information refer to [Practitioner Dashboard](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/build_sites/practitioner_studio/dashboard/){target="_blank"}.

!!!note
    Disabling the Practitioner Dashboard is not available in DX Compose.

## Presentation Designer - New entry points from Authoring portlet <!--UPDATE URL-->

New entry points to Presentation Designer are now available from the Authoring portlet. A new **Read in Presentation Designer** option has been added to the **Read** drop-down menu, allowing you to open a presentation template in read-only mode. The existing **Edit in Presentation Designer** option has been moved from the **More** drop-down menu to the **Edit** drop-down menu. You can additionally switch between the standard WCM HTML Editor and Presentation Designer without leaving the authoring workflow. For more information, refer to [Accessing Presentation Designer](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/wcm_authoring/presentation_designer/access/){target="_blank"}.

## Search V2 - Using in-house CA or PKI for certificates <!--UPDATE URL-->

You can now use certificates from your organization’s certificate authority (CA) or public key infrastructure (PKI) for Search V2 deployments. For detailed instructions, refer to [Using in-house CA or PKI for Search V2 certificates](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/deployment/install/container/helm_deployment/preparation/optional_tasks/optional_new_search_ca_certificates/){target="_blank"}.
