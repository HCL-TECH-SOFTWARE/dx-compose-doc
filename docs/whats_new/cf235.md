# What's new in CF235

The following features and updates are available to customers installing HCL Digital Experience (DX) Compose Container Update CF235 on supported platforms:

- Basic registry and administrator identity are now fully configurable
- DAM Soft Delete
- New How-to article available
- OpenLiberty and JRE versions

## Basic registry and administrator identity are now fully configurable

The basic registry and administrator identity configuration are now fully configurable in DX Compose. This update enables the following capabilities:

- **Disable the basic registry** for LDAP-only deployments by setting `basicRegistry.enabled` to `false`.
- **Customize the realm name** by setting `basicRegistry.realm` to a custom value.
- **Change the administrator username** from `wpsadmin` to a custom value by using `webEngineUser` or `customWebEngineSecret`. When you use LDAP, the administrator user does not need to exist in the basic registry and can be an LDAP user.
- **Change the administrator group** from `wpsadmins` to a custom value by using `webEngineAdminGroup`. When you use LDAP, you can specify an LDAP group DN instead of a basic registry group.

For more information, see [Configuring the default basic registry](../deploy_dx/manage/cfg_webengine/default_basic_registry_configuration.md) and [Configuring the administrator user and group](../deploy_dx/manage/cfg_webengine/configure_default_admin_user.md).

## DAM Soft Delete

The Soft Delete feature provides a safety net for accidental deletions of assets and collections in Digital Asset Management (DAM). Instead of permanently removing items immediately, a soft delete moves them to a **Trash** state where they are hidden from normal views but remain in the database for a configurable period. Items in the Trash can be restored or permanently deleted by authorized users.

For more information, see [DAM Soft Delete](https://pages.git.cwp.pnp-hcl.com/CWPdoc/dx-mkdocs/in-progress/manage_content/digital_assets/configuration/dam_soft_delete/){:target="_blank"}.
