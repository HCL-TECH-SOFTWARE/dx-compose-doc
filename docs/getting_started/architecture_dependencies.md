## Dependencies

For the correct version of Kubernetes to use, see the topic [Kubernetes runtime](https://help.hcl-software.com/digital-experience/9.5/latest/get_started/system_requirements/kubernetes/kubernetes-runtime/){target="_blank"}.

For production purposes, a Lightweight Directory Access Protocol (LDAP) server and DB2 are required. See [System Requirements](system_requirements.md) for more information.
